# Contributor instructions

- Keep the site static and avoid adding a backend or client-side tracking without an explicit product decision.
- Never commit credentials, environment files, private contact data, customer or lead exports, local deployment state, or personal email addresses.
- Treat everything in `public/`, page copy and Git history as publicly visible.
- Preserve accessibility: keyboard focus, semantic headings, readable contrast and 44 px touch targets.
- Keep changes small and aligned with the evidence-based portfolio goal.
- Before committing, run `npm audit`, `npm run check`, `git diff --check` and inspect staged files.
- Use a GitHub noreply address for commits.
